# MacScriptForMouseLikePad

Three compiled AppleScript files (`left.scpt`, `right.scpt`, `up.scpt`) meant
to make a regular mouse perform macOS trackpad-style gesture actions.

The scripts are stored compiled (binary `.scpt`), not as readable source, so
this README can't say exactly what each one does beyond its name — likely
bound to a mouse button or gesture utility to trigger a swipe/navigation
action, but that could not be confirmed from the repo alone.

## Status

A small one-off script collection from December 2024. Not maintained.

## Running it

Not verified. These appear to be double-clickable/`osascript`-runnable
AppleScript files, likely intended to be triggered by a third-party mouse
gesture tool (not included here) rather than run directly.
